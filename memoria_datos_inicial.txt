==============================================================================
  MEMORIA DE DATOS  -  Laboratorio 03  -  Equipo 7
==============================================================================

  La memoria de datos de Logisim es volatil: al iniciar la simulacion
  todas sus palabras valen 0x00000000.  El programa NO necesita datos
  precargados: el mismo codigo escribe la configuracion inicial
  (N = 10) en la direccion 0x00000200 antes de usarla.

  La RAM del diseno es de 256 palabras x 32 bits (1 KiB).  El circuito
  DataMemory toma el indice de palabra de Address[9:2] y el byte dentro
  de la palabra de Address[1:0].  Por eso las direcciones de byte
  0x100, 0x104, ... se convierten en los indices 0x40, 0x41, ...

  Contenido inicial (antes de ejecutar):
     palabras 0x00 - 0xFF : 0x00000000  (256 palabras en cero)

  Mapa de memoria que utiliza el programa:

     Direccion   Indice RAM  Contenido                        Quien lo escribe
     ---------   ----------  ------------------------------   ----------------------
     0x00000200  0x80        0x0000020A  (byte0 = 10 -> N)    main (instruccion SW)
     0x00000100  0x40        0x00000000  S(0)                 serie
     0x00000104  0x41        0x00000001  S(1)                 serie
     0x00000108  0x42        0x00000002  S(2)                 serie
     0x0000010C  0x43        0x00000005  S(3)                 serie
     0x00000110  0x44        0x0000000C  S(4)                 serie
     0x00000114  0x45        0x0000001D  S(5)                 serie
     0x00000118  0x46        0x00000046  S(6)                 serie
     0x0000011C  0x47        0x000000A9  S(7)                 serie
     0x00000120  0x48        0x00000198  S(8)                 serie
     0x00000124  0x49        0x000003D9  S(9)                 serie
     0x00000300  0xC0        0x000003D9  S(9)                 main
     0x00000304  0xC1        0xFFFFFF91  checksum de bytes    main
     0x00000308  0xC2        0x0000000A  cantidad de terminos main

  La pila ocupa las direcciones 0xFFFFFFF4, 0xFFFFFFF8 y 0xFFFFFFFC,
  que corresponden a los indices 0xFD, 0xFE y 0xFF de la RAM.

  Resultados verificados en simulacion (350 ciclos, el PC se detiene en
  el lazo "fin" de la direccion 0x00000044):
     S(0..9) = 0, 1, 2, 5, 12, 29, 70, 169, 408, 985
     0x00000100 = 0x00000000   0x00000104 = 0x00000001
     0x00000108 = 0x00000002   0x0000010C = 0x00000005
     0x00000110 = 0x0000000C   0x00000114 = 0x0000001D
     0x00000118 = 0x00000046   0x0000011C = 0x000000A9
     0x00000120 = 0x00000198   0x00000124 = 0x000003D9
     0x00000200 = 0x0000020A
     0x00000300 = 0x000003D9
     0x00000304 = 0xFFFFFF91
     0x00000308 = 0x0000000A
     $v0 = -111 (0xFFFFFF91)  suma con signo de los bytes bajos (LB)
     $v1 = 10                 cantidad de terminos procesados
     $s3 = 985, $s4 = -111, $s5 = 10, $s6 = 985

  Para cargar datos a mano en la GUI de Logisim: clic derecho sobre
  la RAM -> 'Edit contents'.
